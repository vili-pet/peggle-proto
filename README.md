# Peggle Proto 🎯

HTML5 Peggle-inspired casual game prototype. Täysin toimiva versio, jota voit testata suoraan puhelimella.

## Pelaa nyt (GitHub Pages)

**Linkki:** https://vili-pet.github.io/peggle-proto/

> **Huom:** Ensin sinun täytyy laittaa GitHub Pages päälle (kerran):

### Kuinka laitat Pagesin päälle (30 sekuntia):

1. Mene tähän repositorioon: https://github.com/vili-pet/peggle-proto
2. Klikkaa **Settings** (yläreunassa)
3. Vasemmasta valikosta: **Pages**
4. **Source** → valitse **Deploy from a branch**
5. **Branch** → `main`
6. **Folder** → `/ (root)`
7. Paina **Save**

Sivu on live noin 1-2 minuutin päästä.

## Ohjeet pelaamiseen

- **Käännä puhelin vaakatasoon** (landscape) – paras kokemus
- Vedä sormella ampujasta (ylhäältä) ja päästä irti laukaisemaan pallo
- Tavoite: Osu kaikkiin **oransseihin tappeihin**
- Siniset tapit antavat vähemmän pisteitä
- Sinulla on 10 laukausta per taso
